🎯 QU'EST-CE QUE ATLAS?
================================================================================

Un système d'orchestration automatisée qui transforme une idée de produit
en produit lancé en 35 minutes avec 99% d'automatisation.

Flux: Idée → Claude (conseil) → Validation → CEO orchestre → Agents travaillent

================================================================================
📈 ARCHITECTURE SYSTÈME
================================================================================

Frontend:  React + Next.js 14 (TypeScript)
Backend:   Next.js API Routes
AI/LLM:    Claude Anthropic (Opus 5)
Database:  Supabase PostgreSQL
Deploy:    Vercel

Composants:
• ProductPage         - Page produit + contrôle CEO
• ProjectRefinement   - Chat avec Claude
• ValidationPanel     - Valider/rejeter actions
• AgentGraph/Graphify - Visualiser agents temps réel
• Navbar             - Navigation

================================================================================
🔄 WORKFLOW COMPLET (4 ÉTAPES EN 35 MIN)
================================================================================

ÉTAPE 1: CRÉER PRODUIT (2 min)
├─ Nom, description, utilisateurs cibles, problème
└─ → Produit en base de données

ÉTAPE 2: AFFINER AVEC CLAUDE (20 min)
├─ Poser 5-10 questions stratégiques
├─ Claude répond + propose actions
└─ → 5-10 actions proposées générées

ÉTAPE 3: VALIDER LES ACTIONS (10 min)
├─ Lire chaque action proposée
├─ Approuver 3-5 actions (rejeter optionnel)
├─ Ajouter feedback personnel
└─ → Actions status = "approved" + feedback sauvegardé

ÉTAPE 4: LANCER CEO (1 min)
├─ Cliquer "🚀 Lancer CEO" (bouton devient VERT après validations)
├─ CEO analyse + crée plan 30 jours
├─ CEO crée 4-7 agents spécialisés
└─ → Graphify affiche tous les agents en temps réel!

RÉSULTAT: Orchestration complète en 35 minutes! 🚀

================================================================================
🔐 INTÉGRATION TEMPS RÉEL (GRAPHIFY)
================================================================================

Claude propose → Vous validez → CEO crée agents → Graphify affiche

Statuts Dynamiques:
• 🟢 ACTIVE     = Agent travaille (approvedCount > 0)
• ✅ COMPLETED   = Agent a fini
• 🔴 BLOCKED     = Agent bloqué (rejectedCount > 0)
• ⚫ IDLE        = Pas lancé

Mise à jour: Automatique chaque 5 secondes via API

================================================================================
💾 STRUCTURE BASE DE DONNÉES
================================================================================

projects table:
├─ id, name, description, target_users, problem
├─ status (ideation|validation|architecture|dev|launch)
└─ created_at, updated_at

agent_actions table:
├─ id, project_id, title, description
├─ status (pending|approved|rejected)
├─ user_feedback (votre retour)
└─ details (flexible JSON)

agents table:
├─ id, project_id, name, role
├─ status (active|idle|completed|blocked)
├─ tasks (liste de tâches)
└─ created_at, updated_at

chat_messages table:
├─ id, project_id, role (user|assistant)
├─ message (contenu)
└─ created_at

📋 UTILISATION CORRECTE (ÉTAPE PAR ÉTAPE)
================================================================================

ÉTAPE 1: CRÉER UN PRODUIT
  → Aller à https://atlas-1-mu.vercel.app/create
  → Remplir: Nom, Description, Users cibles, Problème
  → Submit → Redirection auto vers /products/{id}

ÉTAPE 2: AFFINER AVEC CLAUDE
  Section: "💬 Affiner le projet avec Claude"
  → Poser une question (ex: "Quel est mon marché principal?")
  → Claude répond avec: insight + 3 recommandations + question
  → Lire entièrement
  → Répéter 5-10 fois pour bien affiner

  Questions Recommandées:
  • "Résumez mon produit pour valider compréhension"
  • "Quel est mon marché principal?"
  • "Comment me différencier des concurrents?"
  • "Quel MVP minimal pour valider?"
  • "Comment prioriser les features?"
  • "Quel business model?"
  • "Quels sont les 3 plus gros risques?"

ÉTAPE 3: VALIDER LES ACTIONS
  Section: "📋 Actions à Valider"
  Pour chaque action (3-5 minimum):
  → Cliquer sur l'action
  → Lire title + description
  → (Optionnel) Ajouter feedback personnel
  → Cliquer "✅ Approuver" ou "❌ Rejeter"

  Résultat:
  • Status change à "approved"
  • Feedback sauvegardé
  • Compteur augmente
  • Bouton CEO devient VERT

ÉTAPE 4: LANCER CEO
  Bouton en haut à droite: "🚀 Lancer CEO"

  Avant de lancer:
  ✓ Vérifier bouton est VERT (pas gris)
  ✓ Affiche "✅ N actions approuvées"
  ✓ Au moins 1 action approuvée

  Après click:
  • Alert: "CEO a lancé l'orchestration!"
  • Agents créés en DB
  • Graphify actualise

ÉTAPE 5: OBSERVER GRAPHIFY
  Section: "🤖 Graphe d'Agents"

  Affichage:
  • Résumé: 🟢 Actifs | ✅ Complétés | 🔴 Bloqués | ✅ Approuvées
  • Canvas: Agents visuels
  • Liste: Détails + tâches

  Mise à jour: Chaque 5 secondes

  Interprétation:
  🟢 = Agent actif et travaille
  ✅ = Agent a terminé sa tâche
  🔴 = Agent bloqué/en attente
  ⚫ = Agent pas encore lancé

================================================================================
🐛 TROUBLESHOOTING RAPIDE
================================================================================

PROBLÈME: Claude ne répond pas
CAUSE:    Clé API invalide
SOLUTION: Vérifier NEXT_PUBLIC_CLAUDE_API_KEY dans .env.local
          Clé doit commencer par sk-ant-
          Régénérer à: https://console.anthropic.com/account/keys

PROBLÈME: Actions n'apparaissent pas
CAUSE:    Tables Supabase manquantes
SOLUTION: Exécuter supabase.sql dans SQL Editor
          Vérifier tables: projects, agents, chat_messages, agent_actions

PROBLÈME: Bouton CEO reste gris
CAUSE:    Aucune action validée
SOLUTION: Approuver minimum 3 actions
          Status doit être "approved" (pas "pending")
          Actualiser page (F5)

PROBLÈME: Graphify affiche "Aucun agent"
CAUSE:    CEO pas lancé OU agents pas créés
SOLUTION: Vérifier que vous avez cliqué "Lancer CEO"
          Attendre 5-10 secondes (API refresh)
          Actualiser page (F5)
          Vérifier Supabase: agents table doit avoir entrées
