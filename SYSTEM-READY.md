## Common First Steps

### Step 1: Update CEO Instructions
Go to Paperclip → Agents → CEO
Add content from `agents/ceo/ORCHESTRATOR-MODE.md` to system prompt
Test by saying: "I have an idea for a product..."

### Step 2: Set Up Trigger
Pick ONE:
- **Email:** Forward to `paperclip-ceo@domain.com`
- **Slack:** Message `@paperclip-ceo` in workspace
- **Web Form:** Create simple form → webhook to Paperclip
- **iPhone Shortcut:** 4 questions → email

### Step 3: Submit First Idea
Pick something you want to build.
Submit via your chosen trigger.
Watch the magic happen.

### Step 4: Wait 5 Days
Phase 1 validation runs in parallel.
You don't need to do anything.
Check in on Day 5 for decision memo.

### Step 5: Approve & Repeat
If GO: Approve Phase 2, let it run for 2 weeks
If NO: Learn and move to next idea
If PIVOT: Adjust and re-submit

## One Last Thing

This system is built on one core insight:

**Most of the work in product launches is:
- Research (boring, can be automated)
- Planning (structured, can be automated)
- Coordination (repetitive, can be automated)
- Writing (templated, can be automated)**

**The ONLY things that require YOU:**
- Deciding market fit (go/no-go)
- Approving designs and strategies
- Final launch decision
- Revenue goals and course corrections

Everything else? Paperclip handles it.

**So your job becomes: Have ideas, make decisions, celebrate launches.**
